## Format des images
- Format : WebP (ou PNG), fond transparent
- Taille : 600 × 360 px (5:3), 120 Ko maximum
- Vue : profil strict, roue avant à droite, vélo centré (marge ~5 %), même échelle
- Style : « toon », trait épais, aplats de couleur, identique pour les 50
- Nom : NN-marque-modele.webp (minuscules, sans accent)
- Si une image manque, l'appli affiche le dessin générique.
- Droits d'utilisation à obtenir (marques ou illustrateur) avant le lancement public.
